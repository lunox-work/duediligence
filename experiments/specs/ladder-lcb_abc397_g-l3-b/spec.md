# Maximize Distance

A directed graph has edges that all start with weight 0, and you must pick a fixed number of them to set to weight 1. The goal is to make the shortest path from the first vertex to the last vertex as long as possible. The program must output the largest shortest-path distance that any such choice can produce.

Input

The input is given from Standard Input in the following format:
N M K
u_1 v_1
u_2 v_2
\vdots
u_M v_M

Output

Print the answer.
