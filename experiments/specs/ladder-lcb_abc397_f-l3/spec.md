# Variety Split Hard

Given a sequence of integers, cut it into three contiguous, non-empty pieces. For each piece, count how many distinct values it contains. The program must find the largest possible total of these three counts over all ways of making the cuts.

Input

The input is given from Standard Input in the following format:
N
A_1 A_2 \ldots A_N

Output

Print the answer.
