# Reverse Brackets

You are given a balanced parenthesis string, and you may repeatedly pick any contiguous substring that is itself balanced and replace it with its mirror image: reverse its order and swap every opening bracket for a closing one and vice versa. The program must count how many distinct strings can be reached this way, including the original, and report the count modulo 998244353.

Input

The input is given from Standard Input in the following format:
N
S

Output

Print the answer.
