# Minimum Cost Sort

You are given a permutation of the integers 1 through N, and you may repeatedly swap two adjacent elements, where swapping the elements at positions i and i+1 costs i. Compute the minimum total cost needed to sort the permutation into ascending order.

Input

The input is given from Standard Input in the following format:
N
P_1 P_2 \ldots P_N

Output

Print the minimum total cost required to sort P in ascending order.
