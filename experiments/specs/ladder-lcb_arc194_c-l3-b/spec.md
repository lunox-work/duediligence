# Cost to Flip

Two binary sequences A and B of the same length are given, along with a weight for each position. A single move flips one bit of A and then costs the sum of the weights at every position where A holds a 1 after that flip. The program must find the minimum total cost of a sequence of moves that turns A into B.

Input

The input is given from Standard Input in the following format:
N
A_1 A_2 \ldots A_N
B_1 B_2 \ldots B_N
C_1 C_2 \ldots C_N

Output

Print the answer.
