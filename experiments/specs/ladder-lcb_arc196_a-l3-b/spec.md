# Adjacent Delete

A sequence of numbers is reduced by repeatedly removing two numbers that are next to each other, until at most one number is left. Each removal earns the absolute difference of the two numbers removed. The program must find the largest total that can be earned this way.

Input

The input is given from Standard Input in the following format:
N
A_1 A_2 \ldots A_N

Output

Print the maximum possible total score obtained.
