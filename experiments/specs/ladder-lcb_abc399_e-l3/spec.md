# Replace

You are given two equal-length strings of lowercase letters, S and T. In one operation you pick two letters x and y and replace every occurrence of x in S with y. Determine whether S can be turned into T by some sequence of such operations, and if so, find the minimum number of operations needed.

Input

The input is given from Standard Input in the following format:
N
S
T

Output

If it is possible to make S identical to T, print the minimum number of operations required. Otherwise, print -1.
