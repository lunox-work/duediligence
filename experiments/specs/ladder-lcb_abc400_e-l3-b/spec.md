# Ringo's Favorite Numbers 3

A "400 number" is a positive integer that has exactly two distinct prime factors, each of which appears in its prime factorization an even number of times. For each of several given integers A, the program must find the largest 400 number that is at most A.

Input

The input is given from Standard Input in the following format:
Q
\text{query}_1
\text{query}_2
\vdots
\text{query}_Q

Here, \text{query}_i is the i-th query, given in the following format:
A

Output

Print Q lines. The i-th line should contain the answer to the i-th query.
