# Range Power Sum

Given a sequence of integers and a positive integer exponent K, consider every contiguous subarray of the sequence and compute the sum of its elements. Raise each of these subarray sums to the power K and add all the results together. Report this total modulo 998244353.

Input

The input is given from Standard Input in the following format:
N K
A_1 A_2 \dots A_N

Output

Print the answer.
