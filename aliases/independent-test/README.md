# independent-test

Renamed to [`duediligence`](https://www.npmjs.com/package/duediligence). The `independent-test` command runs `duediligence` with the same arguments and exit codes. `INDEPENDENT_TESTS_*` environment variables are read as their `DUEDILIGENCE_*` names, and an existing `~/.independent-tests/` stays the data folder until `~/.duediligence/` exists.

```sh
npx duediligence help
```

Docs, issues and source: [github.com/lunox-work/duediligence](https://github.com/lunox-work/duediligence).
